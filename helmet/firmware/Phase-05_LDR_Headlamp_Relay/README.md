# Phase 5 — LDR Auto Headlamp (Independent Relay Circuit)

No Arduino code for this phase — the LDR is **not connected to either Nano**. It's a separate, independent circuit (its own power source) that uses a relay to switch the 3-LED white headlamp array on in low light and off otherwise.

Verification: visually confirm the relay clicks and the LED array turns on in darkness / off in light — no firmware test needed.
